# Protocol Palace

Plataforma de treinamento em cibersegurança com desafios, quizzes e conteúdo educacional.

## Tecnologias

- Vite + TypeScript
- React 18
- shadcn/ui + Tailwind CSS
- Redux Toolkit
- React Query
- React Router

## Desenvolvimento

```sh
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build de produção
npm run build

# Rodar testes
npm run test
```

## Estrutura

```
src/
  components/   # Componentes reutilizáveis
  pages/        # Páginas da aplicação
  store/        # Redux store e slices
  hooks/        # Custom hooks
  lib/          # Utilitários
```
